关于这个工具

目标用户、数据来源、Mock 说明、增长路径和已知限制，都在这一页。

一、目标用户与痛点

给谁用

  • 中国 AI 视频生成工具创业公司的 CEO / CMO / 增长负责人。
  • 公司大概 10–100 人，正在跟可灵、即梦、Runway、Pika 等竞品抢用户。

什么痛点

  • 竞品今天改价格、明天换落地页、后天发新功能，没时间天天盯。
  • 信息太散，等发现的时候可能已经晚了。
  • 知道竞品在做什么，也不知道哪些值得跟进。

什么时候用

  • 每周增长例会前。
  • 准备投广告、做内容前。
  • 竞品突然降价、发新品时。
  • 老板问「竞品最近在干嘛」时。

相比现在省什么

  • 从每天手动翻竞品官网、广告、搜索词 1 小时，变成 30 秒看报告。
  • 从「知道竞品在做什么」，变成「知道哪些该跟、哪些不用管」。

二、数据来源

  • 公开信息整理：竞品官网、公开新闻、公开内容渠道。
  • 内置竞品数据库：可灵、即梦、Runway、Pika、Sora、海螺 AI。
  • 模拟数据：广告、关键词、定价等细节为模拟，用于演示完整流程。

时间范围

2026 年 Q1 – Q2。

三、Mock 说明

本工具是面试 Vibe Coding 演示项目，明确区分已实现、Mock 和未来计划。

已实现（真实）

  • 输入竞品 → 生成对应报告，换输入结果真的会变。
  • 结果页可分享，链接可直接打开对应结果。
  • 订阅 / 注册提交会写入 Google Sheet（若已配置）。
  • 内置竞品数据库，命中时返回真实整理数据。

Mock（模拟）

  • 关键词、广告、定价、落地页、产品发布、内容渠道数据为模拟。
  • 输入数据库里没有的品牌时，会生成一份模拟报告，并明确标注。
  • MegaHit 注册入口为模拟入口，用于演示转化路径。

未来计划

  • 接入真实关键词工具 API（如 Ahrefs、Semrush）。
  • 接入真实广告数据源。
  • 接入真实 AI API 生成行动建议。
  • 覆盖更多赛道，支持自动监控和每周推送。

四、已知限制

  • 未接入真实广告 API、关键词工具 API 和 AI API。
  • 数据不是实时更新，为一次性整理。
  • 目前只覆盖 AI 视频生成赛道。
  • 未接入真实数据库，数据存在内置 JSON 文件中。
  • Vercel Serverless 环境无本地持久化，订阅记录依赖 Google Sheet。

五、增长路径

第一批用户从哪里来

  • AI 视频生成创业公司的创始人社群、微信群、即刻、小红书。
  • 增长 / 营销相关话题社区（如人人都是产品经理、知乎、V2EX）。
  • MegaHit 现有用户和线索，用免费工具唤回。
  • 同行分享：CMO 把报告发给老板、团队、同行。

分发 / SEO / 分享机制

  • 分享循环：用户生成报告 → 点分享 → 同事打开同一报告 → 也想检查自己竞品 → 订阅或注册。
  • 公开示例报告页：/example/可灵 可被搜索引擎收录，别人搜「可灵竞品分析」时可能找到。
  • 每周订阅：订阅后每周收到竞品变化，形成回访。

用户为什么愿意注册 MegaHit

  • 免费版只给一次快照，注册后可看历史趋势。
  • 免费版只看一个竞品，注册后可追踪多个竞品。
  • 免费版只给简单建议，注册后可解锁完整修复清单和每周推送。

六、验证指标

  • 访问量：首页 PV / UV。
  • 核心功能使用：点「开始侦察」次数、结果页打开次数。
  • 分享：复制分享链接次数。
  • 订阅：订阅提交数（记录在 Google Sheet）。
  • 注册：MegaHit 注册提交数（记录在 Google Sheet）。

说明：本工具为演示版，暂未接入访问统计 SDK，以上为观察计划。
